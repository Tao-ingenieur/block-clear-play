## 自动验证（实际通过）

`cd repo` 后执行：

```powershell
pnpm verify
pnpm demo
pnpm build:web
node tools/package.mjs
node tools/license-inventory.mjs
```

- 42 项测试通过，0 失败/跳过。`pnpm verify` 包含 Core 与 Web 类型检查、Core 覆盖率门槛、Core JS/声明文件构建和编译前后回放比对。
- Core 全部模块的行/分支/函数覆盖率均为 100%，门槛写入 test:coverage 脚本；没有忽略代码的注释。覆盖率不等于完备正确性证明，仍需增加实际手感与跨宿主反例。
- 7-Bag 属性验证：1000 个 seed，每个 10 袋；每袋七种各一次，重放结果一致。
- 100 个 seed 的随机操作序列，最长每局 600 tick，检查矩阵、碰撞、分数整数、恢复后的状态与继续模拟。
- 测试涉及 I/O/JLSTZ 旋转、边界、踢墙、Spin 前角/Mini/升级、消行、B2B/Combo/全清、DAS/ARR、锁定上限、Hold、垃圾、模式结束和非法消息。
- Full Spin 三种消行均有锁定/计分集成检查；Triple 用例从带合法旋转历史的最终状态开始，不能将其夸大为完整三行旋入路径实玩验证。
- 双人模拟覆盖同时攻击、延迟、双败、单方胜利与非法批次的原子拒绝；未测试真实网络。
- 20 个入门残局全部在源码和编译后的 JS 中通过解法验证。
- `pnpm demo`：第一残局四行全清，score=2834，hash=2ce1a8d9，快照恢复前后摘要一致。
- 固定回放 tests/fixtures/seed-17.json：tick=500、score=36、pieces=1、hash=7f3279ab。源码执行、编译后 JS 和浏览器 QA 页全部匹配。
- 依赖台账扫描了当前 Windows 安装的 19 个开发依赖，保存元数据和随包许可/通知；其他操作系统可选包未安装，未来平台构建时再核验。

## 构建产物

- `dist/core/`：编译的 ES modules、.d.ts 和包元数据，供其他宿主复用。
- `dist/web-v0.1.0/`：Vite 直接输出生产构建；HTML/CSS/JS 总原始体积约 69KB，gzip 约 23KB。没有外部素材或运行时 CDN 请求，实际精确字节与 SHA-256 见发布包 manifest.json。
- `dist/web-v0.1.0/` 与 ZIP：静态部署包，只需 HTTP/HTTPS 静态服务。
- 源码以 repo 为唯一维护位置，不生成或保留 source 副本与源码 ZIP；node_modules 和本地缓存由 .gitignore 排除。

本地开发服务和 QA 服务器只用于本轮验证，最终交付以文件与可复现运行说明为准。
